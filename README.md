# Infamy, Infamy!: New Recruit game system

Unofficial New Recruit game system files for **Infamy, Infamy!** (the 2020 core rules with the Errata and FAQ), a game by TooFatLardies.

## About these files
These files are an aid for people who **already own the game**. They let you build
and cost a force in New Recruit, and they carry short rule summaries so you can see
what each option does while you build.

They are not a substitute for the rulebook, and they are not intended to infringe the
copyright of the licence holder of the game or its rules. They are not affiliated with
or endorsed by TooFatLardies. Game names and trademarks belong to their owners.

If you don't own the game, please buy it. These files won't teach you how to play.

## What is in this repository
- `Infamy.gst`: the game system
- `Infamy - Late Republican Romans.cat`
- `Infamy - Early Imperial Romans.cat`
- `Infamy - Britons.cat`
- `Infamy - Gauls.cat`
- `Infamy - Germans.cat`

Each army has its leaders, the Groups from its troop roster with their stat lines and points, and its support options with the limits the book prints. Points and Support are costed separately: the Support total is rolled on the day of the game or agreed beforehand, so you set that limit yourself.

## What is not included
The scenarios, the campaign, the effects of each troop characteristic (they are shown by name only), and the pre-set force lists in the book. Build the same forces from the rosters instead: this costs more points than the printed lists, which are cheaper than the sum of their parts.

## Version
Revision 1. All five armies were tested in the New Recruit app: army selection, the Warlord requirement, points totals, stat lines, units under each heading, and support options with their limits. How a roster looks when exported has not been tested.

## Using them
New Recruit reads a game system from the top of a repository, so you can add this one with
Add or remove games, Add from GitHub and entering `Kelvios/InfamyInfamy` as the repository
(without `https://github.com/`). Or download the files and open the .gst first and the .cat
files after it, in the New Recruit Editor or Builder.

## Updating
When these files change, the `revision` number inside them goes up, so New Recruit offers the update from the same Add from GitHub entry. You don't need to remove and re-add the game system.

## Removal
If you are a rights holder and want anything changed or removed, please open an issue and it will be actioned promptly.
